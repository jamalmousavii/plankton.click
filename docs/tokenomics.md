## مکانیزم سوزاندن (Burning)

### ۱. کارمزد تراکنش
```
۱٪ از هر تراکنش سوزانده می‌شود
مثال: ۱۰۰ توکن پرداخت → ۱ توکن سوزانده
```

### ۲. کارمزد استفاده از LLM
```
۲٪ از هر درخواست LLM سوزانده می‌شود
مثال: ۵۰ توکن برای چت → ۱ توکن سوزانده
```

### ۳. جریمه ورکر
```
۵٪ از استیک ورکر متخلف سوزانده می‌شود
```

### ۴. سوزاندن دوره‌ای
```
هر ۳ ماه: ۱٪ از موجودی فاندریشن سوزانده می‌شود
```

## پاداش ورکرها

### فرمول پاداش
```
Reward = (GPU_Score × Uptime_Factor × Task_Score) / Total_Network_Power
```

## درآمد پلتفرم

### تقسیم درآمد
```
درآمد کل: ۲۰٪

├── ۱۰٪ از ورکرها
│   └── از کل پاداش ورکرها
│
└── ۱۰٪ از کاربران
    └── از کل هزینه استفاده
```

### مثال
```
ورکر: GPU با قیمت 1000 توکن
├── کاربر: 2000 توکن پرداخت می‌کند
├── ورکر: 1700 توکن دریافت می‌کند
├── پلتفرم: 200 توکن (10% ورکر + 10% کاربر)
└── سوزاندن: 20 توکن (1% تراکنش + 2% LLM)
```

## قرارداد هوشمند

### PlanktonToken.sol
```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

import "@openzeppelin/contracts/token/ERC20/ERC20.sol";
import "@openzeppelin/contracts/access/Ownable.sol";

contract PlanktonToken is ERC20, Ownable {
    uint256 public constant MAX_SUPPLY = 1_000_000_000 * 10**18;
    
    constructor() ERC20("Plankton", "PLANKTON") Ownable(msg.sender) {
        _mint(msg.sender, MAX_SUPPLY);
    }
    
    function burn(uint256 amount) public {
        _burn(msg.sender, amount);
    }
    
    function burnFrom(address account, uint256 amount) public {
        _burn(account, amount);
    }
}
```
