# معماری پروژه Plankton Network

## نمای کلی

Plankton Network یک شبکه غیرمتمرکز LLM است که از سه لایه اصلی تشکیل شده است:

1. **لایه کاربر (Frontend)**: رابط کاربری برای ورکرها و کاربران
2. **لایه واسط (Backend)**: API سرور و هماهنگی
3. **لایه بلاکچین (Blockchain)**: قراردادهای هوشمند و پرداخت

## جریان داده

### ۱. جریان درخواست کاربر

```
کاربر → فرانت‌اند → بک‌اند → ورکر (WebSocket) → پردازش → پاسخ
                │                    │ (ورکر نیست؟ 503 WORKER_OFFLINE / مدل نیست؟ 409 MODEL_UNAVAILABLE)
                ▼
          کسر توکن + سوزاندن (فقط پیام‌های سرو شده)
```

### ۲. جریان ماینینگ

```
ورکر → اپلیکیشن → اتصال به شبکه → دریافت درخواست → پردازش → گزارش
                                                    │
                                                    ▼
                                              دریافت پاداش
```

### ۳. جریان پرداخت

```
کاربر → پرداخت توکن → قرارداد هوشمند → تقسیم پاداش
                                    │
                                    ├── ۱۰٪ ورکر
                                    ├── ۱۰٪ پلتفرم
                                    └── ۱٪ سوزاندن
```

## اجزای فنی

### فرانت‌اند (Next.js)
- رابط کاربری چت LLM
- پنل ورکر و کاربر
- اتصال کیف پول MetaMask
- نمایش آمار و اطلاعات

### بک‌اند (Node.js/Express)
- API احراز هویت
- API مدیریت ورکرها
- API مدیریت کاربران
- API پردازش LLM
- API پرداخت

### دیتابیس (PostgreSQL)
- جدول کاربران
- جدول ورکرها
- جدول درخواست‌ها
- جدول تراکنش‌ها

### Ollama
- اجرای مدل LLM
- مدیریت GPU
- بهینه‌سازی عملکرد

### قرارداد هوشمند (BSC)
- PlanktonToken (ERC-20)
- StakingPool (استیکینگ)
- BurnMechanism (سوزاندن)
